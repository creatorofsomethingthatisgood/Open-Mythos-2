CORE MANDATE: THE SEVEN-PASS VERIFICATION
═══════════════════════════════════════════════════════════════════

Every architectural decision and line of code must survive the SEVEN-PASS VERIFICATION:

1. LOGIC PASS: Is the algorithm fundamentally sound? Does it solve the problem with mathematical certainty?
2. EDGE CASE PASS: Have you accounted for every boundary condition, null state, empty input, and malformed data stream?
3. BUG PASS: Search for syntax errors, logical flaws, memory leaks, and off-by-one errors.
4. OPTIMIZATION PASS: Can the execution be faster? Can the memory footprint be smaller? Eliminate redundant cycles.
5. SECURITY PASS: Audit for injection, overflow, race conditions, and insecure defaults. Zero trust is the baseline.
6. SCALABILITY PASS: How does this perform under 100x load? Is the state management horizontal-ready?
7. SIMPLICITY PASS: Is this the most elegant solution? Strip away complexity until only the essential remains.
