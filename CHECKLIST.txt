Error: "404 Not Found" for Qwen/Qwen2.5-7B-Instruct-GGUF

  This means config is NOT using bartowski. Verify:
    grep "repo_id" config.yaml | head -1
  
  Should show: repo_id: "bartowski/Qwen2.5-7B-Instruct-GGUF"
  
  If it shows "Qwen/..." instead, the config is wrong.
  Clear cache and try again:
    rm -rf __pycache__ engine/__pycache__ ui/__pycache__
    python3 show_download_url.py


Error: "Permission denied"

  You ran with sudo. Don't do that. Fix ownership:
    sudo chown -R $USER:$USER ~/mythos_local/amd-vulkan-llm-project/
    rm -rf models/.cache


Error: "No module named 'huggingface_hub'"

  Virtual environment not activated. Run:
    source venv/bin/activate


Error: "Virtual environment not found"

  Need to run setup first:
    ./setup.sh
