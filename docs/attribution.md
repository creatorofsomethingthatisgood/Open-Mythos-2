## Built on the shoulders of

### Local inference

- **[llama.cpp](https://github.com/ggerganov/llama.cpp)** — the engine that makes local LLM inference possible
- **[llama-cpp-python](https://github.com/abetlen/llama-cpp-python)** — Python bindings used by Mythos
- **[Qwen 2.5](https://huggingface.co/Qwen)** — the default model family
- **[bartowski](https://huggingface.co/bartowski)** — GGUF quantizations used out of the box
- **[Hugging Face Hub](https://huggingface.co)** — model distribution

### Retrieval-augmented generation

- **[ChromaDB](https://github.com/chroma-core/chroma)** — vector store
- **[sentence-transformers](https://github.com/UKPLab/sentence-transformers)** — embeddings
- **[PyPDF2](https://github.com/py-pdf/PyPDF2)** — PDF ingestion

### Interfaces

- **[Rich](https://github.com/Textualize/rich)** — terminal UI rendering
- **[Gradio](https://www.gradio.app)** — local web UI
- **[FastAPI](https://fastapi.tiangolo.com)** — API server backing the Vercel frontend
- **[React](https://react.dev)** + **[Vite](https://vite.dev)** + **[Tailwind](https://tailwindcss.com)** — web frontend

### Tooling & infrastructure

- **[Jekyll](https://jekyllrb.com)** — what's rendering this page
- **[GitHub Actions](https://github.com/features/actions)** — CI and Pages deploys
- **[npm](https://www.npmjs.com/)** + **[Vercel](https://vercel.com)** — distribution
