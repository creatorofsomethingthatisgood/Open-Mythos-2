# Contributing to Open Mythos-2

We welcome bug reports, fixes, features, docs, and general feedback. The full guide lives in [`CONTRIBUTING.md`](https://github.com/creatorofsomethingthatisgood/Open-Mythos-2/blob/main/CONTRIBUTING.md) in the repo root.

---

## At a glance

1. **Fork** the repo or — if you have collaborator access — branch directly.
2. **Branch** off `main` with a descriptive name (`fix/...`, `feat/...`, `chore/...`, `docs/...`).
3. **Run tests** before opening a PR: `pytest tests/` after the venv is set up via `./setup.sh`.
4. **Open a PR** against `main`. Use the checklist in the PR template.
5. **Be patient** — this is a community project. The maintainer reviews when they can.

For security-sensitive changes, please use the **private security advisory** link above rather than opening a public issue.
